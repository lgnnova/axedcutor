# Setup Guide
1. Download this thing
2. Open axedcutor.exe and click Yes in the Windows prompt (only aviable on Windows by the way)
3. If it says that its a virus then either disable your antivirus or set it to safe if possible (false warning, executors inject DLL's so thats why some antiviruses may think its malware)
4. Press Inject and get a Velocity key (Roblox, not external)
5. Restart, press Inject again and paste your key
6. Restart again if needed and press Inject while having ROBLOX open
7. Type some lua code for example: print("Axedcutor Works") to verify it works (to see printed stuff check the dev console, keybind: F9 [some laptops/PCs may require to press both Fn/Function + F9])
8. Enjoy
